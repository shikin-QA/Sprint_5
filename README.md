# Sprint_5 — автотесты для Stellar Burgers

Учебный проект: автотесты на Selenium для сервиса Stellar Burgers.

## Что проверяется
- Регистрация (успешная и с коротким паролем)
- Вход (с главной, через личный кабинет, через форму регистрации, через форму восстановления пароля)
- Переход в личный кабинет
- Переход из личного кабинета в конструктор (по кнопке и по логотипу)
- Выход из аккаунта
- Переключение разделов конструктора: «Булки», «Соусы», «Начинки»

##Запуск
```bash
pip install -r requirements.txt
pytest -v
Тесты запускаются с автоматическими ретраями (pytest.ini)
